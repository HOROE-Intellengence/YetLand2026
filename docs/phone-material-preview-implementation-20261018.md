# 小手机完整预览与素材留存：实现及本地验收

状态：已于 2026-10-19 04:24 UTC 与手机端 UI 合并部署至生产，四个容器更新完成，原有访问状态已恢复。历史补录新增 344 份素材、失败 0 份；详细备份、镜像和线上验收回执见 [合并发布记录](phone-material-ui-deployment-20261019.md)。本页以下截图均为本地合成内容，不含真实用户聊天。

## 已确认的行为

- 后台按用户、类型和记录查看小手机留存，用手机宽度、自适应或全屏展示。普通聊天读取设备最终保存的消息，保留图片、音频、视频及附件引用；长会话按每 50 条分段。
- 自定义 App/游戏展示设备实际捕获的画面与关联数据；图片可打开完整留存文件、100% 查看并下载，音视频使用浏览器播放器，文本/JSON 可阅读，其他资源下载后打开。
- 用户素材自动进入管理员素材库，按用户及来源筛选，与巡查记录互相跳转。同一用户同一原始字节散列去重，不跨用户复用身份。
- 图片不超过 2 MiB 时保留原字节；超过时转为 WebP，先降质量，必要时再缩尺寸，结果不超过 2 MiB。素材库同时记录压缩前后体积。音视频及其他资源保留原文件字节。
- 长篇预览将完整 JSON 拆为 UTF-8 二进制片段传输、还原，正文和资源列表分页显示，避免以摘要替代原文或一次渲染数百万字符。内部传输片段不显示为用户素材。
- 继续使用管理员鉴权、单向留存和只读预览。未增加后台编辑、恢复或跨端写回。HTML 画面经过清理并放入禁脚本沙箱，不能操作用户设备或调用模型。
- 新版设备第一次打开时重新补传已有内容，保留原设备身份与递增版本号；不强制用户重新生成内容。

## 历史数据与容量边界

生产只读审计时，“可可”对应 `usr_9e10d02d`，有 197 条调用、15 条巡查、35 份原素材库记录，巡查库有 227 份资源；部分历史正文或文件本身缺失。没有找到其由已知测试脚本创建的证据，因此**不能认定为测试账号**，也不以临时邮箱推断账号性质。

该用户的历史请求中识别到 3 张不同的完整用户图片，重复出现在 22 份请求中，现已补入生产素材库并核验。全站此次新增 344 份素材，恢复 10 张不同的历史聊天图片；另有 24 份无法解析的旧请求未补造，原记录保留不变。被截断的请求、未保存的本地文件、旧版生成图仅剩的缩略图无法还原原件；界面会说明缺失状态，原设备仍持有时可在新版打开后补传。

当前保留约束：图片输入不超过 64 MiB、解码不超过 4000 万像素；音视频/其他单资源沿用 16 MiB 限制；每用户巡查资源合计 256 MiB；完整预览 JSON 不超过 64,000,000 字节、资源清单不超过 10,000 项；自定义 App/游戏保留最近 4 个捕获画面。缺失或超限会标记部分预览。非图片不会为适应体积限制而有损重编码。外部资源只有明确引用的公开 HTTPS 图片走受控抓取；其他远程链接不承诺自动归档。

## 补录用法

在 API 仓库根目录运行，`--root` 必须是实际 API 持久目录，不能指向仅有 `state.json` 的目录。默认只读预检同时统计巡查资产和可解析的历史用户图片：

```sh
node --import ./apps/api/node_modules/tsx/dist/loader.mjs scripts/backfill-phone-materials.mjs --root /path/to/api-data
```

完成一致性备份并进入已授权维护窗口后，才运行：

```sh
node --import ./apps/api/node_modules/tsx/dist/loader.mjs scripts/backfill-phone-materials.mjs --root /path/to/api-data --apply
```

脚本重建素材索引与记录关联，不生成消息、不补造缺失内容。检查输出中的 `failedAssets`、`unreadableCalls`、`addedMaterials`，失败项应先定位再重跑。生产执行时保持 API 单一写入进程；不要在业务进程继续写入时另开补录写入进程。

## 发布与回滚安排

API 与后台、国内/COM/社区三个小手机均需更新。先使用发布时实际运行镜像作为基线做限定文件覆盖，API 先于小手机上线；工作区存在其他并行任务修改，不能整体打包整个工作区，尤其不能整份替换含其他改动的 `routes/phone.ts` 和 Next host 代理。

本次核心文件是 API `services/image-materials.ts`、`phone/inspection.ts`、`routes/admin/materials.ts` 及 phone 路由素材上传/远程图片部分；共享预览契约/资源类型；手机 `phone-inspection-*`、`phone-chat-inspection.ts`、`phone-preview-capture.ts`、聊天/动态持久化通知及 host 有界请求体；后台 `InspectionPreview`、`RetainedMedia`、`Materials`、`PhoneInspectionBrowser` 和带查询参数的路由。脚本 `scripts/backfill-phone-materials.mjs` 单独放入发布包。
