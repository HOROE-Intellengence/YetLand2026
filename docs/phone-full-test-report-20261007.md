## 未通过与问题

1. **跨功能记忆断链。** 小手机端已存储“紫色纸鹤、8.88 元”，原聊天在空历史的新会话问相同事实却回答“《时间简史》初版样书、两千英镑”。代码中 `apps/api/src/routes/chat.ts` 仍调用 `getUserProfile(userId)`，手机使用角色及作用域画像，读取路径没有连通。原聊天→小手机方向未据此认定通过。
2. **语音未取得音频。** 指定文本朗读 HTTP 500 / PHONE_INTERNAL_ERROR；独立提供商探针定位到 UND_ERR_CONNECT_TIMEOUT。普通通话终态 VOICE_UPSTREAM_CONNECTION_FAILED。高质量通话产生文字后终态 HQ_STAGE_FAILED。创建语音会话成功不算音频通过。
3. **记忆人物归属有偏差。** 浏览器聊天中 AI 角色发送的礼物、红包被侧袋写成“用户霍金发送”，需要明确事件中真实用户与 AI 角色的身份，不能只凭写入成功判语义正确。
4. **入口来源限制。** localhost:5173 可以桥接；127.0.0.1:5173 会停在“请从夜阑功能选择页进入小手机”，因为配置的父页面 origin 不同。未放宽来源校验。
5. **联系人搜索体验。** 按角色名搜索失败，角色 ID 搜索成功；实现仅匹配微信号与 ID。
6. **Lint 未全通过。** Web/Admin 检查共 3 errors、5 warnings；errors 为 Admin client.ts 两个未用导入及 Policy.tsx 未用 PolicyList。未顺带修改无关管理后台。
7. **接口契约扫描有警告。** phone 契约被扫描器视作缺失/孤立，路由含 inline zod；此项不等价运行时接口失效。
8. **生图与 3D 并非已接入。** 托管初始化 enableImageGeneration=false，middleware 拦截 image-generation/tripo 原路由。仅补 API key 不会自动恢复这些玩法，需托管接入实现。
