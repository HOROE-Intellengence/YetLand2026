# 夜阑服务器小手机浏览器实测记录

日期：2026-10-08（America/New_York）。范围：发现问题，不修复、不发布、不调整服务器配置。

## 结论

本轮被浏览器自动化操作通道阻塞，未完成逐应用、多轮功能实测。没有足够证据确认小手机业务缺陷，也不能标记功能通过。

## 已观察

- `https://ingress.yetland.com/__preview/login` 能完成预览放行并打开主站。
- 最初使用预览凭据在产品“手机号 + 密码”登录，页面提示“账号或密码不正确”。用户随后说明产品账号为邮箱账号，并已手动登录；此项不计为已确认产品缺陷。
- 手动登录后，主站嵌入的 `https://phone.yetland.com/` 能显示手机桌面。
- 桌面 DOM 显示 19 个应用入口：聊天、手记、音乐、日历、查手机、购物、阅读、在场、共创、游戏、应用市场、小红书、栖所、剧情、漫卷、冒险、工坊、资源集市、独家特调。入口存在仅为观察，不代表实际可用。
- 直接访问手机域名提示“请从夜阑功能选择页进入小手机”；不将入口限制判为缺陷。

## 测试阻塞与复核

1. Chrome 扩展通道连接失败，返回 `nodeRepl.fetch request failed`。
2. 切换到内置浏览器后，多次操作或读取耗时约 21–55 秒；部分组合调用超过 60 秒，导致会话重置。
3. 小手机 iframe 内“聊天”语义定位能找到一个可见按钮，但点击返回 `Click target is no longer available`；之后 DOM 仍显示桌面。
4. 依据截图点击聊天图标，同样返回目标不可用。
5. 浏览器调试鼠标输入尝试超时，随后页面显示桌面编辑状态。由于按压与释放可能因通道延迟分离，此现象不判为产品交互缺陷。已再次发送释放事件。
6. iframe 内“完成”按钮定位成功，但键盘 Enter 返回 `Keyboard focus root is no longer available`。
7. 最后已执行页面刷新，并核对 DOM 已返回主站落地页，桌面编辑状态已离开。
