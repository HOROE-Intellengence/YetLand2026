# 夜阑 · 星座数据格式规范（行式 DSL）

> 用途：定义「星座生成工具」产出、可直接粘进 **后台 → 星座编辑器 → 文本导入** 文本框的数据格式。
> 解析器实现见 `apps/admin/src/routes/constellation-dsl.ts`，校验与渲染共用 `@yelan/shared` 的 `ConstellationSchema`。

---

## 1. 这是什么

一段星座 = 若干**星点**（带坐标）+ 若干**连线**（连接两个星点）。
本格式用纯文本逐行描述它，方便任何工具/LLM 生成后粘贴导入。导入时会解析 → 校验 → 载入编辑器画布（**不自动保存**，需人工确认后点「保存」）。

---

## 2. 坐标系（务必理解）

星座叠加在角色卡上，坐标是相对卡片的百分比：

| 轴 | 含义 | 取值范围 |
|----|------|----------|
| `x` | 水平，0=卡片左边缘，100=右边缘 | **0 ～ 100** |
| `y` | 垂直，0=卡片**上**边缘，100=下边缘 | **-40 ～ 100** |

- `y` 允许**负值**：`y < 0` 表示星点浮在卡片**上方**（悬于顶部边界之外），这是星座「从卡片顶端升起」效果的关键。
- 坐标可带小数（如 `50.5`）。超出范围会被**拒绝并报错**（不会自动夹取）。

```
        y=-40  ┌───────── 浮空区（星点可在此）─────────┐
        y=0    ╞════════════ 卡片上边缘 ════════════╡
               │                                     │
        y=100  └───────────── 卡片下边缘 ───────────┘
              x=0                                   x=100
```

---

## 3. 语法

逐行解析，规则如下：

### 3.1 注释与空行
- 以 `#` 开始到行尾的内容是注释，被忽略（支持**行内注释**：`A 50 -25  # 顶点`）。
- 空行忽略。

### 3.2 星点行：`id x y`
- 三个字段：`id`、`x`、`y`。
- `id`：星点标识，只允许 **字母 / 数字 / 下划线**（`A-Za-z0-9_`），长度 1～40，**不得重复**。
- `x`、`y`：数字，落在上表范围内。

```
A 50 -25
B 25 -10
```

### 3.3 连线行（三种等价写法）
- `A-B`（连字符，推荐）
- `A->B`（箭头，与 `-` 等价，**方向不敏感**）
- `A B`（两字段空格分隔）
- 两端必须是**已定义的星点 id**；不允许自环（`A-A`）。
- 无向：`A-B` 与 `B-A` 视为同一条，重复会被静默去重。

```
A-B
A->C
B D
```

### 3.4 分隔符容错
字段之间可用 **空格 / 英文逗号 `,` / 中文逗号 `，`**，多余空白无所谓：

```
A , 10 , 20
B，30，40
```

### 3.5 顺序
星点与连线**可任意混排**，标题注释（如 `# 星点` / `# 连线`）只是给人看的，不影响解析。建议先写星点再写连线，便于阅读。

---

## 4. 完整示例

```
# 沈言志 · 钻石/皇冠状
# 星点 id x y   (x:0..100, y:-40..100)
A 50 -25     # 顶
B 25 -10
C 75 -10
D 50 15
E 35 45
F 65 45

# 连线 from-to
A-B
A-C
B-D
C-D
D-E
D-F
E-F
```

导入后即得到 6 个星点、7 条连线的星座。

---

## 5. 校验规则（不满足即拒绝，并指出行号）

1. 语法可识别（每行要么是星点 `id x y`，要么是连线 `A-B`）。
2. `id` 合法（`[A-Za-z0-9_]{1,40}`）且**全局唯一**。
3. `x ∈ [0,100]`，`y ∈ [-40,100]`。
4. 连线两端 id **必须已定义**，且 `from ≠ to`。
5. 数量上限：星点 ≤ 64，连线 ≤ 128。
6. 允许空星座（无星点无连线）。

> 解析器会**一次性收集所有错误**（不止第一条），方便生成工具批量修正。

### 错误示例
```
A 120 0      # ✗ x 超出 [0,100]
A 0 -50      # ✗ y 超出 [-40,100]
A 0 0
A 1 1        # ✗ id 重复
A-Z          # ✗ 连线引用了不存在的星点 Z
A-A          # ✗ 连线两端相同
hello world  # ✗ 无法识别
```

## 6. 给「生成工具 / LLM」的产出约束（可直接放进 prompt）

请严格按以下规则输出，**只输出文本本身，不要代码块包裹、不要多余解说**：

- 每个星点一行：`id 空格 x 空格 y`。`id` 用大写字母 `A B C …`，依次不重复。
- `x` 取 `0~100`，`y` 取 `-40~100`；想让星点浮在卡片上方就用负 `y`。
- 连线每行一条：`起点id-终点id`（如 `A-B`）。只能连已出现的星点，不要自环、不要重复。
- 可用 `#` 写注释/分组标题，但不是必须。
- 数量：星点建议 4～12 个，连线 ≤ 128。
- 构图建议：顶部用 1～2 个负 `y` 的点制造「升起感」，主体落在 `y 10~60` 之间，整体左右大致对称更耐看。

输出样例：
```
A 50 -20
B 20 15
C 80 15
D 50 45
A-B
A-C
B-D
C-D
```

---

## 7. 反向导出

编辑器里点「复制为文本」，会把当前画布按本格式导出（并复制到剪贴板），可用于：
- 把手工调好的星座反喂给生成工具当样例；
- 备份 / 版本对比。

导出与导入**互逆**：导出的文本再导入应得到完全相同的星座。
