# 计划一 · 滚动轮播角色选择（纯前端）

## 4. 目标效果拆解

参考图一是**5 槽位舞台轮播**，不是普通卡片等比缩放。视觉必须优先满足下面的硬规格：

| 槽位 | offset | 视觉要求 | 内容 |
|---|---:|---|---|
| 中心卡 | 0 | 最大、最实、最高，正中压顶层 | 显示名称/标签，可点击进入 |
| 近左 / 近右 | -1 / 1 | 中等宽度，中等透明度，低于中心卡 | 内容可淡化，但不能抢中心卡 |
| 远左 / 远右 | -2 / 2 | **细长竖条**，明显窄于近侧卡，接近参考图两侧薄片 | 隐藏文字，只保留卡片轮廓/光感 |
| 更远 | abs > 2 | 不可见 | `visibility:hidden` + 禁止 pointer |

| 需求 | 机制 |
|---|---|
| 中心放大、两翼递减 | 每卡按"距中心偏移 `offset`"算 `scale / opacity / translateX / blur / z-index` |
| 渐变 | 随距离的连续衰减 + 视口左右边缘 `mask-image` 渐隐 |
| 渐入渐出 | 远端卡 `opacity→0` 滑出窗口；进场整体 `fadeUp` |
| 线性加速减速进入 | 切换时对 `transform/opacity/filter` 加 `transition`，缓动 = ease-in-out 型 `cubic-bezier`（先加速后减速） |
| 左右箭头 + 多种交互 | `activeIndex` ± 1（循环），见 §5.4 |

## 5. 技术路线：slot-driven 的 5 槽位舞台轮播

**核心**：维护 `activeIndex`，每卡渲染时算 `offset`（环形最短距离），再把 offset 映射到固定槽位变量。TSX 管状态，CSS 管表现。不要只做连续 `scale()`，否则远侧卡会变成"小卡片"，做不出参考图的细长条。

**不采用** CSS `scroll-snap` 方案：其"随距离衰减 + 居中放大"依赖 `animation-timeline: view()`（兼容性差），且缓动不可控。transform 方案对每项的 scale/opacity/缓动有完全控制权，且数学可抽纯函数单测。

### 5.1 环形偏移（建议抽纯函数 `circularOffset`）
```ts
// n = 卡片总数，active = 当前居中索引，i = 该卡索引
export function circularOffset(i: number, active: number, n: number): number {
  if (n <= 0) return 0;
  let off = (((i - active) % n) + n) % n; // 0 .. n-1
  if (off > n / 2) off -= n;              // 折到最短环形距离
  return off;
}
// 验证：n=5 → {-2,-1,0,1,2} 对称；n=3 → {-1,0,1}；n=4 → {-1,0,1,2}（偶数轻微不对称，可接受）
// n=2 → {0,1}：另一张恒在右侧、左侧空（仅 2 卡，无法对称，可接受）。每张卡只渲染一次 → 无 React key 重复问题。
```

### 5.2 槽位模型（默认值，先按视觉准，再微调）

建议抽纯函数 `slotForOffset(offset)`，返回下面这些变量。数值是起点，不是神谕；验收以参考图观感为准。

| offset | tx | width | height | scale | opacity | blur | textOpacity | zIndex |
|---:|---:|---:|---:|---:|---:|---:|---:|---:|
| -2 | `-44vw` | `42px` | `340px` | `0.88` | `.36` | `1.5px` | `0` | 70 |
| -1 | `-23vw` | `260px` | `430px` | `.9` | `.68` | `.6px` | `.55` | 80 |
| 0 | `0` | `340px` | `520px` | `1` | `1` | `0` | `1` | 100 |
| 1 | `23vw` | `260px` | `430px` | `.9` | `.68` | `.6px` | `.55` | 80 |
| 2 | `44vw` | `42px` | `340px` | `.88` | `.36` | `1.5px` | `0` | 70 |
| abs > 2 | — | — | — | — | `0` | — | `0` | 0 |

- `abs > 2` 的卡：`opacity:0 + pointer-events:none + visibility:hidden`。
- 远侧竖条不要压缩内部文字；文字区域直接 `opacity: var(--card-text-opacity)`，远侧为 0。
- 移动端用 media query 缩小中心宽高，例如中心卡 `min(72vw, 340px)`，近侧卡可只露边缘，远侧条可隐藏。
- 实现方式：inline 注入 `--slot-x / --slot-w / --slot-h / --slot-scale / --slot-opacity / --slot-blur / --slot-text-opacity`，CSS 消费这些变量。

### 5.3 缓动 / 边缘 mask / 进场
```css
:root, .viewport {
  --cf-ease: cubic-bezier(0.45, 0, 0.15, 1); /* 先加速后减速 = ease-in-out */
  --cf-dur:  520ms;
}
.card {
  transition: transform var(--cf-dur) var(--cf-ease),
              width     var(--cf-dur) var(--cf-ease),
              height    var(--cf-dur) var(--cf-ease),
              opacity   var(--cf-dur) var(--cf-ease),
              filter    var(--cf-dur) var(--cf-ease);
}
/* 容器边缘渐隐：两侧细长条融进背景 */
.viewport { -webkit-mask-image: linear-gradient(90deg, transparent, #000 18%, #000 82%, transparent);
                    mask-image: linear-gradient(90deg, transparent, #000 18%, #000 82%, transparent); }
/* 进场：复用 globals.css 的 fadeUp，可加 stagger */
```

### 5.4 交互（D2：四种全做）
| 方式 | 实现要点 |
|---|---|
| 键盘 ←/→ | 场景 `useEffect` 挂 `window.keydown`，← = `step(-1)`，→ = `step(+1)`；卸载时移除 |
| 鼠标滚轮 | 累加 `deltaX`(优先)/`deltaY` 到阈值(~40)才 `step(sign)`，加 ~400ms 锁防连跳；`preventDefault` 防页面滚，监听器需 `{ passive: false }` |
| 触摸/拖拽 | `pointerdown` 记 startX + `setPointerCapture`；`pointerup` 若 `|dx| > 60px` 则 `step(-sign(dx))`（右滑→上一张）。v1 阈值提交即可；连续跟手位移列为后续打磨 |
| 点侧卡居中 | `offset !== 0` → `setActive(该卡 index)`；`offset === 0`（中心卡）→ `pickCharacter(c)` 进入对话 |

```ts
const step = (dir: number) => setActive((a) => (a + dir + n) % n); // 环形
```
- 无障碍：箭头按钮用真实 `<button aria-label>`；卡片优先继续用真实 `<button>`；中心卡加 `aria-current`。
- **prefers-reduced-motion**：`matchMedia('(prefers-reduced-motion: reduce)')` 命中时，关闭 transform 位移与 blur，仅保留 opacity 切换（或瞬切）。

## 9. P2B 预留：数据模型（矢量真理源，定义在 `packages/shared`）
```ts
// packages/shared/src/types/character.ts
export interface ConstellationPoint {
  id: string;   // 稳定 id（A/B/C…），供 edge 引用 & 编辑 key
  x: number;    // 0–100 矢量空间
  y: number;    // 允许负值（如 -40..100），让星座可浮于卡片上方

export interface ConstellationStyle {        // 全局风格（D5），全部可选，缺省取 token 默认

  breatheSpeed?: number;// 呼吸相对速度，默认 1
}
export interface Constellation {

  style?: ConstellationStyle;
```

## 10. P2B 预留：编辑器三件套（D4）
三者共用**一个文本格式**和**一份编解码器**：

### 10.1 文本格式（前缀行式，容错、可整段粘贴）

### 10.2 共享编解码器（`packages/shared`，纯函数 + 单测）

- `serializeConstellationText(c): string`：反向产出上述文本（供编辑已有星座时回填 textarea）。
