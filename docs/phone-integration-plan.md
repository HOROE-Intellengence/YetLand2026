# 夜阑小手机托管接入

基线：`phone-integration-baseline`（34552e1）；开发分支：`codex/phone-integration`。
基线提交保存接入前已有的夜阑账号、语音、网关和小手机代码，不表示这些均由本轮实现。

## 已确认边界

- 小手机是登录后功能选择页的独立入口，原聊天、通话、API 等入口及流程保持；新增行为仅在小手机模式启用。

- 不另建跨端同步，复用已有存储，玩法状态允许保存在当前浏览器。
- 长期及跨功能记忆由已有偏好记录侧袋与上下文压缩侧袋承担。
- 角色统一使用夜阑 ID、设定与访问权限；预设、世界书和正则复用原执行逻辑，配置归入角色卡编辑。
- 小手机取消用户侧 API、模型、云部署及提示词绑定入口，服务端统一托管。
- 语音消息/通话复用夜阑语音能力，跨功能上下文与侧袋记忆连通。
- 新玩法计费只保留空接口，不实现扣费；不更改夜阑既有计费。
- 富消息复用小手机标记解析与气泡组件；虚拟红包不连接支付或烛火。
