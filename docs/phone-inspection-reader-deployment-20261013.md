# 小手机对话阅读与内容巡查发布记录

2026-10-13 已完成发布并恢复公众访问。按照本次授权，在本机以线上镜像为基础构建、上传并替换 API/可视化后台与国内、COM 两个小手机镜像；主站 Web 镜像未更换。

小手机对话记录按用户、角色、来源应用和会话组织，默认连续阅读，支持正文搜索、状态与时间筛选、上下文折叠、字号、浅深色和全屏。新请求附带应用、会话、操作及轮次标识。历史日志缺少会话标识时按日期与分支归组，界面明确标记，不能把这些历史分组理解为完整的原始会话。

内容巡查改为分类列表与阅读面板，提供“用户预览”“正文阅读”和资料详情。预览覆盖自定义 App/游戏的最近实际画面、视觉小说场景与对白/选项、访谈对话及成刊、动态图片与评论、购物商品与订单、阅读章节。图片可放大，已留存的音视频使用原生播放器；预览支持手机宽度、自适应与全屏。

新版小手机单向补传预览结构及本地可获取的媒体。自定义 App/游戏只读捕获当前 DOM、表单展示值及 Canvas 画面，并处理沙箱内的 Blob 素材。后台 HTML 预览经过清理，在禁止脚本的沙箱中显示；媒体通过管理员鉴权读取，受归属、类型和体积限制。普通用户没有巡查读取、恢复或运维写回接口，用户本地删除仍保留服务器最后收到的快照。

历史日志未保存的图片、音频、视频和运行画面无法凭空还原。原设备打开新版小手机及对应应用后，会补传仍可获取的内容；缺失、超限或无法取得的素材明确标记为部分预览，后台不会主动抓取外部媒体或调用模型补造画面。

本次使用限定文件覆盖构建，API/共享逻辑 12 个文件、后台 10 个文件、每个小手机 16 个文件；共享文件在两类镜像间重叠。线上源码哈希全部核对通过，小手机保留原生产依赖与 Next 15.5.12。工作区中其他语音、账号和主站改动未打包；后台预存的 `VoiceRecords.tsx` 改动也未随本次发布进入镜像。

实际验证结果：

- 9 个文件中的 46 项相关回归测试全部通过，包含旧巡查写入兼容、媒体归属、管理员权限、删除留存、会话分类/顺序及预览捕获；API、后台和小手机类型检查通过，后台 Vite 构建与两个生产小手机构建通过。
- 实际 API 镜像在隔离环境通过二进制媒体、权限、兼容写入和会话阅读检查；两个实际小手机镜像通过代理集成检查，媒体字节与类型、追踪字段转发正确，未登录访问及管理员路径转发被拒绝，3D 路径保持 404。
- 本地浏览器以合成内容检查 App 画面切换、视觉小说、访谈成刊、动态与评论、商品订单、阅读章节、图片放大、实际 WAV 播放结束和 WebM 播放、字号/主题与全屏退出。
- 发布后 API 健康，三个更新容器均无重启；四个公众根入口均返回 200，国内与 COM 的未鉴权巡查读取均返回 401。小手机握手、语音配置和后台静态资源检查通过。
- 生产后台浏览器通过加密 SSH 隧道回看，验证分类、作者筛选、历史正文、连续对话、18px 字号、浅色及退出全屏；截图使用既有合成验收账号。COM 入口的直接浏览器自动化超时，故该入口只计入 HTTPS/API 检查，不计为直接浏览器验收。
- 时间筛选通过 API 检查；工具未成功填入浏览器原生日期输入，因此不声称日期选择器完成浏览器验收。本次未重新执行真实设备完整使用流程、模型生成或语音采集/听感验收。

发布验收查询没有调用外部模型，没有向生产写入合成业务数据。验收时共有 297 条调用记录、31 个归组结果、59 条巡查记录和 6 位世界观资料拥有者；这些数量是发布时快照。维护窗口中，完整状态 JSON、原有对话/巡查业务字段及语音数据库内容指纹保持一致。预览使用新增独立表，对话新增追踪字段兼容旧写入，不以历史备份覆盖业务数据。

已在停止业务写入后备份整个持久目录，包括 `state.json`、SQLite 及 WAL；配置备份涵盖 Compose、环境配置、Caddy 和相关证书/配置卷。备份归档完整读取校验通过，各 SQLite `quick_check` 通过。
