# 小手机用户入口与运维巡查

本次将平台技术配置与诊断入口从托管小手机中隐藏，保留用户创作和个人选择。后台只留存巡查依据，不提供小手机内容跨设备同步、下载恢复或运维下发覆盖。

## 用户入口

隐藏模型/API 接入、平台提示词输出协议、Token 预算、自动总结间隔、原始错误输出、调试记录和技术清理入口。运行失败显示可理解的重试提示，诊断资料留在受管理员鉴权保护的巡查记录中。

保留私有角色补充设定、世界书、文本替换规则、创作要求、语言与显示选择、自动记忆及来源选择、手动整理记忆、共创改稿确认、作品编辑与删除、自建游戏和自定义 App。启动刷新平台 API 绑定时，保留用户自己的预设、世界书和文本规则。

## 可视化后台

- 角色管理新增“世界观”和“小手机角色自定义”页签。当前角色世界书与用户设备留存的世界观分别可读。
- 新增“小手机内容巡查”，按用户、标题和类型查询，查看正文、关联角色、设备、留存时间和本地删除标记。
- 留存故事、视觉小说、共创章节及人物档案、冒险世界和记录、日记、访谈、自建游戏草稿及存档、自定义 App、阅读正文和批注等文本内容。
- 用户 HTML/脚本只显示为文本，不在后台执行。

## 留存边界

用户本地内容保持原有存储方式。联网使用新版小手机后单向上报变更；离线编辑不会被阻塞，重新联网或再次进入时自动补传。旧设备的历史内容需在该设备进入新版后才能留存。

删除本地作品后，后台标记“本地已移除”，保留最后已收到的巡查正文。每条记录最多 100 个正文段落、每段 20 万字符、合计 50 万字符；超限会明确标记“部分正文”，不裁剪用户本地原文。媒体二进制不通过本接口留存。

普通用户只能提交自己的巡查资料，不能读取后台记录。后端按认证用户和设备隔离记录，并拒绝过期修订与伪造归属；未提供用户读取、恢复或后台编辑巡查内容的接口。留存不会调用外部模型。

## 验证

相关回归测试 91 项通过；共创托管间隔与用户改稿选择另有 1 项测试通过。API、后台与小手机类型检查通过。浏览器已验证角色和世界书保存、隐藏技术参数、离线补传、后台正文展示、脚本不执行、本地删除后的留存，以及新设备不恢复另一设备作品。

线上 7 项浏览器验收通过，无页面脚本错误；包含实际角色编辑、共创技术参数隐藏、离线正文补传、后台世界观与正文页面、新设备隔离、脚本只作为文本展示及删除后留存。两个小手机容器均返回 HTTP 200，3D 路径均返回 404。实际浏览器验收使用 COM 备用入口；本次未重跑完整语音或生图流程。
