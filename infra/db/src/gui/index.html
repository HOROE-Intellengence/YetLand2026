默认只读模式（事务里 SET TRANSACTION READ ONLY）。改 schema 或 INSERT/UPDATE 请勾选"写入"开关。 写入仅用于临时调试。结构变更必须走迁移文件。

⚠ 危险区

DROP SCHEMA public CASCADE → 重建 → 重跑全部迁移。 所有数据立即清空。仅在本地开发库用。需要环境变量 MIGRATE_ALLOW_DESTRUCTIVE=true，否则按钮不可点。
