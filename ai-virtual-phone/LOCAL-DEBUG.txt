夜阑小手机：托管接入调试

入口：http://localhost:5173 → 开始体验 → 小手机 → 登录夜阑。
小手机是功能选择页的独立功能，原聊天、普通通话、高质量通话和 API 保留。
不要直接打开 3001 作为登录入口；托管模式需要主站提供已验证的登录态。

启动
- 先运行夜阑 API（8787）和主站前端（5173）。
- 双击本目录 start-local.cmd 启动小手机（127.0.0.1:3001）。
- .local/ 保存本地日志与 PID，已被 Git 忽略。
- 非本机部署需要同时设置主站 VITE_PHONE_URL、手机 NEXT_PUBLIC_YELAN_WEB_ORIGIN、
  手机 YELAN_API_ORIGIN，并启用 YELAN_PHONE_MANAGED/NEXT_PUBLIC_YELAN_PHONE_MANAGED。
  NEXT_PUBLIC 与 VITE 配置需在构建时设置，来源必须与浏览器实际 origin 一致。

托管边界
- API Key、模型和角色访问权限由夜阑 API 逐次处理，浏览器只拿托管占位配置。
- 角色 ID 共用夜阑；管理员在原角色编辑页管理补充预设、世界书和正则。
- 用户仅可在小手机角色页修改自己的私有角色规则；公共角色只读。
- 设置、资源配置和快捷 API 绑定入口在托管模式隐藏。
- 玩法状态仍用原 IndexedDB/localStorage，按夜阑用户隔离；未新增跨端同步。
- 事件交给现有偏好记录侧袋，上传失败保留本地待处理记录。
- 语音入口接现有普通/高质量通话；气泡朗读单独使用现有 TTS。
- 虚拟红包不接支付；新增玩法计费保留空接口。
